# Portfolio de Pablo García

Sitio estático con mis casos de automatización con IA: bots de WhatsApp e Instagram, CRM y sistemas a medida.

**Verlo online:** https://pablo-gabriel-garcia.github.io/portfolio/

Por confidencialidad no se muestran nombres, marcas ni datos de clientes. El CRM inmobiliario de las capturas es un prototipo propio con datos ficticios.

## Contenido

- `index.html`: el sitio completo (HTML y CSS en un solo archivo, sin dependencias).
- `img/`: capturas del prototipo de CRM (datos de prueba) y del flujo del cotizador, con los nombres del cliente ocultos.
